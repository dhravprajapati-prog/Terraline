## 🏗️ Project Architecture

This repository is structured into two main components:

- **`frontend/`**: Modern responsive web application built with **React**, **Vite**, **Tailwind CSS**, and **Three.js** / **Lucide Icons**. Automatically deployed to **GitHub Pages**.
- **`backend/`**: REST API built with **Django** and **Django REST Framework** for handling leads and portfolio project inquiries.

---

## 🚀 Live Website Deployment

The frontend is automated to build and deploy to **GitHub Pages** via GitHub Actions:
- **Deployment URL:** [https://dhravprajapati-prog.github.io/Terraline/](https://dhravprajapati-prog.github.io/Terraline/)
- **Workflow:** [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)
- **Settings Requirement:** Ensure **Settings → Pages → Build and deployment → Source** is set to **GitHub Actions**.
